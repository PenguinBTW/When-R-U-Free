### Highlights

- **Local-First & Fully Offline:** Complete student timetable comparison that runs entirely on-device with no mandatory account creation, email sign-up, or cloud connection.
- **Privacy-Centric P2P Sharing:** Exchange timetables via live high-density QR codes or shareable Base64URL text strings. Built-in camera scanner with preview confirmation.
- **Microsoft 365 Auto-Import:** Delegated read-only calendar sync via OAuth 2.0 PKCE. Automatically filters non-class events, converts timezones, and deduplicates imports.
- **Smart "Free Now" Dashboard:** Live friend status chips showing who is free right now and when their next lesson starts ("till HH:MM").
- **Proportional Visual Timeline:** Week view displaying shared free blocks scaled by duration, collapsing non-relevant busy periods into clean skip dividers.
- **"I'm Actually Busy Then" Overrides:** Carve out one-off busy time for doctor visits or study sessions without editing your recurring weekly timetable.
- **Local Break Alerts:** Background notifications scheduled on-device before upcoming shared breaks naming who else is free.
- **Comprehensive Quality Assurance:** 58 unit and widget tests covering algorithm correctness, UI responsiveness, and edge-case handling.

### Components Added

#### 1. Core Services & Models
- `AvailabilityService`: Mathematical interval intersection, class carving, boundary merging, and meetup rankings.
- `NotificationService`: Scheduled local notifications using `flutter_local_notifications` and `timezone`.
- `TimetableShare`: Base64URL encoding/decoding schema with versioning and payload size guards.
- `GraphAuth` & `GraphCalendar`: Public-client PKCE authentication and Outlook weekly calendar view parser.
- `FirestoreDataStore`: Modular dormant cloud sync layer with anonymous authentication and friend code lookup.
- Models: `Lesson`, `Friend`, `BusyBlock`, `FreeSlot`, `UserProfile`.

#### 2. User Interface (Material 3)
- `ModeChoiceScreen`: Honest launch screen routing between Sync and Offline modes.
- `OnboardingScreen`: Fast name-based onboarding with optional starter timetable.
- `HomeScreen`: Dashboard featuring live free-now chips, next all-free break, best weekly meetups, and today's schedule.
- `WeekScreen`: Visual timeline with adaptive free blocks, skip dividers, and full-group highlights.
- `TimetableScreen`: Mon–Sun tabs, swipe-to-delete cards, and conflict warnings.
- `FriendsScreen`: Group roster, include/exclude toggle switches, demo data loader, and manual friend timetable editor.
- `ScanScreen`: Camera QR scanner powered by `mobile_scanner`.
- `GraphImportScreen`: 4-step wizard for Microsoft 365 setup, sign-in, username selection, and class review.
- `SettingsScreen`: Day window sliders, backup export/import dialogs, notification preferences, and developer tools.

#### 3. Companion Server (`server/`)
- Express server providing `GET /health` and `POST /api/overlap` JavaScript implementation of the interval intersection algorithm.
